## 👋 Sobre mim

Engenheiro de software focado em **backend Java** (Spring Boot, JPA/Hibernate, SQL) e, mais recentemente, em **ferramentas desktop com Rust**. Fundador da **MonolithLabs**, laboratório de software em Recife que cria produtos e segue responsável por eles depois do lançamento.

- 🏗️ Construindo produtos na [MonolithLabs](https://monolithlabs.com.br/)
- 🦀 Explorando Rust em apps de alto desempenho para Windows
- ☕ Dia a dia: APIs REST, bancos relacionais e arquitetura limpa
